# Cozy Cafe ☕

A simple and interactive cafe website built using HTML, CSS, and JavaScript.

## Features
- Responsive cafe website design
- Interactive food and drinks menu
- Menu category filters
- Dynamic order total calculation
- Dark and light mode
- Customer feedback form
- Cafe opening hours display

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Ridabatool512/Cafe.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
